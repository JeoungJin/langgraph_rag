# 금융 Q&A 에이전트 (RAG + Tool 사용 Agent)

우리은행 상품설명서(`data/woori.pdf`)를 근거로 답하는 RAG에, 주가·환율 조회, 계산, 일반 금융 지식 답변을 더한 **Tool 사용 에이전트**입니다.
LangChain `create_agent`(LangGraph 기반)로 만들었고, 어떤 Tool을 몇 번 어떤 순서로 호출할지 에이전트가 스스로 정합니다.

## 질문 유형별 처리

| 질문 유형 | 처리 방식 | 예시 |
|---|---|---|
| 우리은행 상품 문서 | `search_company_docs` Tool → FAISS 검색(RAG), 출처 페이지 표시 | "예금담보대출 얼마나되는 거야" |
| 주가 | `get_stock_price` Tool (Yahoo Finance) | "삼성전자 주가는?" |
| 환율 | `get_exchange_rate` Tool (open.er-api.com) | "달러 환율은?" |
| 숫자 계산 | `calculate` Tool (이자·한도·환산을 암산하지 않고 계산) | "3000만원 연 3.5% 6개월 세후 이자는?" |
| 그 밖의 금융 질문 | Tool 없이 LLM이 직접 답변 | "DSR이 뭐야?" |
| 금융과 무관한 질문 | 정중히 거절 | "오늘 날씨 어때?" |

## 에이전트 동작 방식

```
질문 ─▶ [에이전트(LLM)] ─▶ Tool 호출 ─▶ 결과 확인 ─┐
            ▲                                       │
            └───── 부족하면 다시 판단·재호출 ◀──────┘
                          │ 충분하면
                          ▼
                     최종 답변 (+ 출처·인용 검증)
```

- **다단계 처리:** 질문이 여러 단계면 단계를 나눠 Tool을 순서대로 호출합니다.
  예) "1000만원 예금 담보대출 한도를 달러로 환산하면?" → 문서 검색(95%) → `calculate` → 환율 조회 → `calculate`
- **재검색:** 검색 결과가 없거나 질문과 맞지 않으면 검색어를 바꿔 최대 2번 더 검색합니다.
- **계산은 Tool로:** 한도·이자·환산 같은 숫자는 암산하지 않고 `calculate`로 계산합니다.
- **최대 단계 수:** `rag.py`의 `RECURSION_LIMIT`(기본 15)로 무한 반복을 막습니다.
- **출처 검증:** 문서를 쓴 답변은 근거 페이지를 표시하고, `[번호]` 인용이 올바른지 확인합니다.

대화 기록도 유지합니다. 최근 5턴은 원문으로, 그보다 오래된 대화는 요약으로 압축해 LLM에 전달합니다.

## 폴더 구조

```
RAG_Project/
├─ data/woori.pdf            # 검색 대상 문서 (WON플러스 예금 상품설명서)
├─ .env                      # OPENAI_API_KEY (git 제외)
└─ src/
   ├─ rag_app/               # 메인 앱
   │  ├─ config.py           # 모델, 청크, 검색 설정
   │  ├─ indexer.py          # PDF 로드 → 청크 분할 → FAISS 인덱스 생성/로드
   │  ├─ rag.py              # 에이전트(create_agent) 구성, ask(), 출처·인용 검증
   │  ├─ market_tools.py     # 주가·환율 Tool
   │  ├─ calc_tools.py       # 계산 Tool (안전한 수식 평가)
   │  ├─ memory.py           # 대화 기록 + 5턴 초과 시 요약 압축
   │  ├─ prompts.py          # 시스템·요약 프롬프트
   │  ├─ app.py              # 콘솔 앱
   │  ├─ web.py              # Streamlit 웹 앱
   │  └─ faiss_index/        # 생성된 벡터 인덱스
   ├─ finance_agent/         # 이자·상환액 계산 Tool 중심의 별도 에이전트 실험
   └─ 05 ~ 13/               # 차시별 실습 코드
```

## 설치

Python 3.12 가상환경(`.venv`)을 사용합니다.

```powershell
cd C:\RAG_Project
.venv\Scripts\activate
pip install -r requirments.txt
pip install langchain-openai pypdf streamlit
```

> `requirments.txt`(파일명 오타 그대로)에는 `langchain-openai`, `pypdf`, `streamlit`이 빠져 있어 따로 설치합니다.

프로젝트 루트에 `.env` 파일을 만들고 OpenAI 키를 넣습니다.

```
OPENAI_API_KEY=sk-...
```

## 실행

```powershell
cd C:\RAG_Project\src\rag_app

# 웹 화면
..\..\.venv\Scripts\streamlit run web.py

# 콘솔
..\..\.venv\Scripts\python app.py
```

처음 실행하면 `faiss_index/`가 없을 때 PDF로 인덱스를 자동 생성합니다.

### 문서를 바꿀 때

`config.py`의 `DOC_PATH`를 바꾸고 **`faiss_index` 폴더를 삭제한 뒤** 다시 실행하세요.
인덱스가 이미 있으면 PDF가 바뀌어도 다시 만들지 않습니다.

## 웹 화면 기능

- 입력창은 기본(68px)의 2배 높이이고, 글이 길어지면 자동으로 늘어납니다.
- 지난 대화 아래에 새 질문·답변이 이어져 자연스럽게 스크롤됩니다.
- 답변 아래에 출처 페이지와 사용한 Tool을 표시합니다.
- 첫 화면에서 예시 질문 버튼을 눌러 바로 질문할 수 있습니다.
- 사이드바에서 대화 기록(최근 원문 / 압축 요약)을 확인할 수 있습니다.
- "지우기" 버튼은 화면과 대화 기록을 함께 초기화합니다.

## 주요 설정 (`src/rag_app/config.py`)

| 항목 | 값 | 설명 |
|---|---|---|
| `LLM_MODEL` | gpt-4o-mini | 답변 생성 모델 |
| `EMBED_MODEL` | text-embedding-3-small | 변경 시 인덱스 재생성 필요 |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` | 500 / 50 | 문서 분할 크기 |
| `TOP_K` | 5 | 검색 문서 수 |
| `MIN_SCORE` | -0.01 | 검색 점수 하한 |

대화 기록의 원문 유지 턴 수는 `memory.py`의 `MAX_TURNS`(기본 5), 에이전트의 최대 단계 수는 `rag.py`의 `RECURSION_LIMIT`(기본 15)에서 바꿉니다.

## 테스트용 질문

순서대로 입력하면 맥락 이해와 대화 압축을 확인할 수 있습니다.

1. 예금담보대출 얼마나되는 거야
2. 그럼 1000만원 예금 있으면 얼마까지 빌려?
3. WON플러스 예금 중도해지하면 이자는 어떻게 돼?
4. 그건 3개월 미만이면 몇 %야?
5. 삼성전자 주가는?
6. 달러 환율은?
7. 엔화는?
8. 처음에 내가 뭘 물어봤고 그때 한도 비율이 얼마라고 했지?

6턴째부터 오래된 대화가 요약으로 압축되며, 8번에서 첫 질문을 기억하면 정상입니다.

에이전트의 다단계 호출은 아래 질문으로 확인합니다. 답변 아래 "사용한 Tool"에 여러 Tool이 순서대로 표시되면 정상입니다.

- 1000만원 예금 담보대출 한도를 달러로 환산하면 얼마야?
- 예금 3000만원을 연 3.5%로 6개월 맡기면 세후 이자는? 세율은 문서 기준으로

## 알아두실 점

- 환율은 시장 참고값이며 은행 고시 환율과 다를 수 있습니다.
- 주가는 Yahoo Finance의 비공식 엔드포인트를 사용하므로 지연되거나 일시적으로 막힐 수 있습니다.
- 계산이 섞인 답변은 문서를 근거로 썼어도 `[번호]` 인용이 빠질 수 있으며, 이 경우 화면에 "인용 표시가 확인되지 않았습니다" 경고가 나옵니다.
- 단순한 Tool 호출 중심의 에이전트이며, 장기 계획이나 외부에 행동을 하는 Tool(송금 등)은 없습니다. 모든 Tool은 조회·계산 전용입니다.
- 모델이 gpt-4o-mini라, 맥락이 애매한 후속 질문은 잘못 해석할 수 있습니다. 대상을 명시하면 정확도가 올라갑니다.
- 투자 권유나 수익 보장 표현은 하지 않도록 프롬프트에 제한해 두었습니다.
